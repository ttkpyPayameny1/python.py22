GitHub Connect

পরবর্তী ধাপে GitHub OAuth দিয়ে repository permission নিতে হবে। শুধু ইমেইল ও username দিয়ে অন্যের account-এ deploy করা যায় না।

Deploy checklist

  • ✓ GitHub repository public/private access যাচাই
  • ✓ requirements.txt ও start command পরীক্ষা
  • ✓ deployment logs সংরক্ষণ
  • ✓ subscription validity পরীক্ষা
  • ○ Provider OAuth/API credentials — configure required
Fast Deploy / Slow Deploy-এর বাস্তব queue ও worker এই starter-এ এখনো সংযুক্ত নয়।
